# Sources and attribution

Polish is an independent project. It is inspired by public discussion of
distribution-aware fine-tuning for writing, including:

- [Rosmine's public announcement](https://x.com/rosmine/status/2056406211369541947)
- [Hamel Husain's public experiment](https://x.com/HamelHusain/status/2077165638255304898)
- [Deft's public Distribution Fine-Tuning announcement](https://deftwriting.com/blog/introducing-distribution-fine-tuning)
- [Rosmine's public technical article](https://rosmine.ai/2026/05/18/fixing-llm-writing-with-distribution-fine-tuning/)

The repository does not copy proprietary code, private beta information, or
private service internals. Concepts from public sources are reimplemented and
tested independently. Source descriptions and quotations, if any, remain the
property of their respective authors.
